# Wolf Backpack

Wolf Backpack is a vanilla datapack that gives tamed wolves 15 inventory slots. It supports Minecraft Java Edition 26.3.

## Installation

1. Download the ZIP from [GitHub Releases](https://github.com/Ketket-s-Datapacks/datapack-wolf-backpack/releases) or [Modrinth](https://modrinth.com/project/wolf-backpack).
2. Place the ZIP in your world's `datapacks` folder.
3. Run `/reload` in-game or restart the server.

## Using the backpack

- Right-click your tamed wolf with a chest to equip it.
- Sneak and right-click to open its backpack while the wolf is sitting or standing.
- Use shears to remove the backpack. If the wolf dies, the items it was carrying drop.
- Earn **A Helping Paw** by equipping a backpack and **Ready for Adventure** by filling all 15 slots. Both appear under **Ketket's Datapacks**.
